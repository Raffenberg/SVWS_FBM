# Fortbildung: Betreute Installation von VirtualBox für Einsteiger


::: info Veranstaltungsunterlagen – keine vollständige Anleitung
Diese Seite hält Themen und gegebenenfalls Begleitlinks einer Fortbildung fest. Die mündliche Demonstration ist damit nicht vollständig dokumentiert. Frühere Aussagen zum „aktuellen“ Stand gelten für den damaligen Zusammenhang.

Für die praktische Arbeit: [VirtualBox und Debian-VM](/Fachberatung_Anleitungen/Test-_und_Schulungsserver/VirtuaBox_SchulungsClient/Virtualbox_Installation/). Fehlende Ausarbeitungen stehen im [Inhaltsstand](/fortbildung/inhaltsstand).
:::

Inhalte:

+ Gemeinsame Installation eines WeNoM-Servers auf einem privaten oder von der Bezirksregierung bereitgestellten **Windows-Rechner**.
+ Ziel ist, dass ihr nach der Fortbildung einen laufenden WeNoM-Server auf eurem Rechner habt, um damit zu experimentieren.

Zielgruppe:

+ Einsteiger ohne Vorkenntnisse in Virtualisierung
