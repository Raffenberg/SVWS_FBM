# Fortbildung: Betreute Installation von Proxmox für Einsteiger


::: info Veranstaltungsunterlagen – keine vollständige Anleitung
Diese Seite hält Themen und gegebenenfalls Begleitlinks einer Fortbildung fest. Die mündliche Demonstration ist damit nicht vollständig dokumentiert. Frühere Aussagen zum „aktuellen“ Stand gelten für den damaligen Zusammenhang.

Für die praktische Arbeit: [Proxmox-Schulungsumgebung](/Fachberatung_Anleitungen/Test-_und_Schulungsserver/Proxmox_Schulungsserver/). Fehlende Ausarbeitungen stehen im [Inhaltsstand](/fortbildung/inhaltsstand).
:::

Inhalte:

+ Gemeinsame Installation von Proxmox auf einem Debian 13 - Server (auch für Schulungsserver sinnvoll)
+ Auf dem Proxmox kann dann unter anderem ein WeNoM-Server installiert werden

Zielgruppe:

+ Einsteiger ohne Vorkenntnisse in Virtualisierung

Voraussetzungen:

+ Ein Server mit bereits installiertem Debian 13

Hinweise:
