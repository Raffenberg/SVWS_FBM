# Testdatenbanken nach Schulform

Nutze diese Bestände, um Funktionen kennenzulernen und Fehlerbilder ohne echte Schuldaten nachzustellen. Manche Bestände enthalten bewusst besondere oder fehlerhafte Konstellationen. Prüfe die Beschreibung, bevor Du daraus einen allgemeinen Programmfehler ableitest.

<NavigationOverview path="/Datenbanken/testdaten/" label="Schulform" />

## Einen Bestand auswählen

1. Wähle die Schulform und lies die Eigenschaften der Datei.
2. Für Migrationsversuche benötigst Du einen geeigneten SchILD2-Ausgangsbestand; für einen SVWS-Test kann eine SQLite-Sicherung passen. Der [Steckbrief](/Datenbanken/steckbrief) nennt auch die offiziellen SQLite- und MDB-Sammlungen.
3. Nutze ein getrenntes Schema und halte die ursprüngliche Datei unverändert vor.
4. Prüfe, ob Dein gewünschter Testfall tatsächlich enthalten ist.

Ein Verweis auf eine Sammlung ist keine Zusicherung, dass jede dortige Datei mit jedem Release funktioniert. Für eine Veranstaltung wähle stattdessen die [modulbezogenen Schulungsdaten](../schulungen/).
